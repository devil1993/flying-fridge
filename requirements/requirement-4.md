## Funcational requirement
- First is tasks. It has description of the task. An optional target date. On the dashboard the target date is used to colorcode the tasks. The user can assign himself/herself a task so that others don't do it. There should be a section for already assiged tasks for a user. 
- Next is notice. This is a simple info. That stays on the notice board for one month or until anyone puts it down. The publisher can mark it as permanent, which makes it stay untill someone pulls it down. They can mark it as important as well which adds a color code. 
- Lost and found is where someone puts in something they are looking for untill someone found it or the poster takes it down. I am not sure how we timeline this, probably the posting date is useful here. 
- Pantry is where we put information about food. When it was made, how long it is likely to stay good and the approx quantity for understanding the amount. Anyone can reduce/increase the amount or mark them as consumed to remove them from list.
