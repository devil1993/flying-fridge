The last feature required is a more informed dashboard. We want 2 things here.

- Below the overview, there should be a split view. The user can either see one of those and move between them by taping.
- The first view is recent items. It shows items accross all types with +-2 days of relevant time. The items without a date appears at the bottom.
- The items appearing would be color coded as per type.
- The second view is a calendar. It shows the current month with timed items appearing on the grid as dots. Tapping one day opens the first view but for the date tapped on.
- When any day other than today is opened in the first view, a button appears to go back to today. 

This is the overview.
